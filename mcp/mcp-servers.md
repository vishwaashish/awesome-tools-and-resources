# MCP Servers

MCP servers host AI agents, tools, and prompts in a shared environment.

## Typical Features

- Endpoint orchestration
- Tool integration
- Secure access controls

## Use Cases

- Multi-agent workflows
- Custom agent hosting
- Experimental deployments

## Servers

- [Agent QA](https://github.com/vostride/agent-qa) - FSL-1.1-ALv2 source-available QA harness and MCP server for defining, validating, running, and triaging natural-language web and mobile tests.
