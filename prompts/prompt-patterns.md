# Prompt Patterns

Prompt patterns are reusable structures for guiding AI behavior. Use them to make interactions more consistent, reliable, and easier to scale.

## Common Prompt Patterns

- **Few-shot**: Provide examples before asking for output.
- **Instruction**: Give a clear command with expected output format.
- **Roleplay**: Ask the model to act as a specific persona.
- **Constraint**: Limit response length, style, or format.
- **Chain-of-thought**: Ask the model to explain reasoning steps.
- **Comparison**: Request pros/cons or tradeoffs.

## How to Use Patterns

1. Identify the goal.
2. Choose a pattern that matches the task.
3. Provide context and constraints.
4. Ask for structured output.

## Examples

- Few-shot: "Example 1... Example 2... Now do..."
- Instruction: "Summarize this article in 3 bullet points."
- Roleplay: "You are a software architect. Recommend..."
- Constraint: "Keep the answer under 100 words."
- Chain-of-thought: "Explain your reasoning step-by-step."
