# Prompt Examples

This page contains practical examples for common AI tasks.

## Summarization

- "Summarize the following text in 3 bullet points."
- "Write an executive summary of this report for a product manager."

## Brainstorming

- "Generate 10 creative product ideas for remote collaboration tools."
- "List alternative names for a mobile health app."

## Coding

- "Review this JavaScript function for readability and performance issues."
- "Refactor the following Python code to use list comprehensions."

## Learning

- "Explain the difference between supervised and unsupervised learning like I'm 10."
- "Create a study plan for learning prompt engineering in 4 weeks."

## Writing

- "Rewrite this paragraph to be more concise and professional."
- "Convert this list into a cohesive blog outline."
