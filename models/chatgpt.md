# ChatGPT

ChatGPT is an OpenAI conversational model optimized for dialogue, creative writing, and general-purpose assistance.

## Strengths

- Strong conversational capabilities
- Flexible prompt handling
- Good at writing, summarizing, and brainstorming

## Best Uses

- Interactive chat assistants
- Content generation
- Code explanation and review

## Tips

- Use clear instructions.
- Specify format and role.
- Chain-of-thought prompts can improve reasoning.
